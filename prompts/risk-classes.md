- **`contained`:** changes behavior, but stays inside the topic of the pull request. It touches no public API, no database schema, no build file and no dependency, and nothing that is security-relevant.
- **`structural`:** changes a public API, a database schema, the build, dependencies or security-relevant code, or touches files outside the topic of the pull request.

When a change fits two classes, the riskier one counts.
